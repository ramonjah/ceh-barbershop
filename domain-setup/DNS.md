# Подключение ceh-barber.ru

Целевой домен: ceh-barber.ru. Сайт: ramonjah/ceh-barbershop, GitHub Pages.

В DNS-панели домена требуются записи:

| Тип | Имя | Значение |
| --- | --- | --- |
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | ramonjah.github.io |

Существующие конфликтующие записи A/AAAA/CNAME для @ и www нужно проверить до изменения. Записи почты не менять. Если домен не делегирован, сначала включить DNS-серверы провайдера.

Домен подключён в GitHub Pages. DNS-записи сохранены в панели Jino 12 октября 2026 года. Проверить выпуск сертификата и включение Enforce HTTPS.
