# ЦЕХ — барбершоп в Ейске

Мобильная страница контактов: запись через виджет DIKIDI №220108, звонок, Telegram, WhatsApp, Instagram, ВКонтакте и маршрут в Яндекс Картах.

Статическая страница без сборки и внешних зависимостей. Основной файл — `index.html`, оформление — `style.css`. Для просмотра запустите `python3 -m http.server 8765` в папке проекта.

Адрес: Ейск, Коммунистическая, 21. Телефон: +7 (900) 000-85-93.

Кнопка отзывов ожидает подтверждённую ссылку на карточку организации в Яндекс Картах. Карточка ЦЕХ не обнаружена поиском на момент создания; ссылки на другие организации не используются.

Telegram использует ссылку по номеру телефона. Доступность перехода зависит от настроек поиска по номеру у владельца аккаунта. При наличии публичного username лучше заменить ссылку на него.

Для GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Оформление

Светлый фон и круглый векторный логотип в компактной шапке. Первый экран — короткий цикл из трёх видео процесса стрижки без звука, с приглушённым цветом. `assets/ceh-process.mp4` — монтаж 13,5 секунд; исходные ролики не изменяются. До начала воспроизведения показывается кадр с мягким зелёным переливом; при запрете автозапуска остаётся статичный кадр и доступна кнопка запуска. Видео приостанавливается вне экрана и в скрытой вкладке. Системная настройка уменьшения движения отключает автозапуск и декоративные анимации.

Светлая кнопка записи расположена в нижней части видео и движется вместе со страницей, без закреплённой панели. Надпись «Записаться» и контурный календарь окрашены в цвет логотипа #354b3c; шрифт — Manrope. Кнопка остаётся неподвижной, по её поверхности медленно проходит мягкий блик; нажатие даёт короткий отклик. Системная настройка уменьшения движения отключает анимацию. Видео отображается в исходных цветах без цветового фильтра и затемняющего слоя. Оформление — `assets/process-film.css` и `assets/minimal-booking.css`, воспроизведение — `process-film.js`. Шрифт хранится локально с лицензией.

`station-board.js` каждые 4,5 секунды меняет фразы «Следующая остановка — ЦЕХ» и «Мужской стиль. Точная работа.» через анимацию табло. Контакты, адрес и предложение добавления на главный экран собраны в компактный блок. Локальные редакторы, варианты и изображения из `design-previews/` не входят в публикацию.

## Домен

Основной адрес: https://ceh-barber.ru/. DNS обслуживает Jino; сайт публикуется GitHub Pages из main. Настройки подключения описаны в domain-setup/DNS.md.

## Добавление на главный экран

manifest.webmanifest и app-install.js добавляют мобильное предложение через 8 секунд. iOS показывает инструкцию Safari, Android использует beforeinstallprompt при наличии, иначе инструкцию меню Chrome. В режиме standalone предложение скрыто; закрытие откладывает его на 7 дней. Кеширование и офлайн-режим не используются, чтобы обновления страницы оставались свежими.

## Виджет записи

Кнопка использует официальный скрипт DIKIDI `widget2.min.js` и ссылку `https://dikidi.net/record?widget=220108`. Скрипт загружается асинхронно; до его загрузки ссылка открывает непосредственно форму записи. Форма открывается модальным окном на всех устройствах (`start=1`). На телефоне окно приспущено, адаптировано по ширине и имеет доступную кнопку закрытия; `booking-widget.js` добавляет подписи и поддержку клавиатуры. SMS-подтверждение записи через виджет требует средств на SMS-балансе проекта; баланс проверяет владелец перед публикацией.
